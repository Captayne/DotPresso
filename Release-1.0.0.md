## DotPresso 1.0.0 – die erste Version

Markdown und Text im echten Textmodus auf dem Nadeldrucker.

**Herunterladen:** `DotPresso-1.0.0-Setup.exe` unten unter „Assets“.
Windows 10/11, 64 Bit. Light ist kostenlos, Pro wird mit einem Lizenzschlüssel freigeschaltet.

### Enthalten
- Editor mit Vorschau, die genau so umbricht wie der Drucker
- Markdown: fett, kursiv, unterstrichen, breit, Überschriften, Listen, Tabellen
- Draft und Schönschrift (LQ), 10–20 cpi
- Bilder als Punktgrafik mit einstellbarer Helligkeit
- MatrixFont für Sonderzeichen
- Copy&Print-Hotkey Strg+Alt+N
- Druck über USB ohne Treiber
- Pro: Ausrichtung und Blocksatz, Draft/LQ und Zeichendichte je Absatz, Rahmen zeichnen, Aufräumen, Bilder aus der Zwischenablage, Netzwerkdrucker, .prn-Dateien

### Hinweise
- Windows SmartScreen kann warnen, weil das Setup nicht signiert ist: „Weitere Informationen“ → „Trotzdem ausführen“.
- Reagiert der Hotkey nach der Installation nicht, einmal ab- und wieder anmelden.
